# WP-CONFIG: Local Configuration Management

> **Phase**: MVP Enhancement | **Priority**: HIGH

## Summary

Provide seamless first-run experience with automatic system profiling, intelligent model recommendations, and persistent configuration management. Users should be able to transcribe audio out-of-the-box with minimal friction.

## System Profiling

Profile the user's system to recommend an appropriate transcription model.

### Metrics Collected

| Metric | Method | Purpose |
|--------|--------|---------|
| Available RAM | `sysinfo` crate | Determine max model size |
| CPU cores | `std::thread::available_parallelism` | Inference threading |
| CPU architecture | `std::env::consts::ARCH` | ARM vs x86 optimizations |
| GPU availability | Platform APIs | Hardware acceleration |
| GPU VRAM (if available) | CUDA/Metal/Vulkan query | GPU model loading |
| Disk space | `fs2` or platform APIs | Model storage capacity |
| Platform | `std::env::consts::OS` | Platform-specific defaults |

### System Profile Tiers

| Tier | RAM | GPU | Recommended Model | Rationale |
|------|-----|-----|-------------------|-----------|
| **Minimal** | < 4GB | None | `whisper-tiny.en` (~75MB) | Lowest memory footprint, English-only |
| **Low** | 4-6GB | None | `whisper-base.en` (~140MB) | Good quality, fast inference |
| **Medium** | 6-8GB | Integrated | `whisper-small.en` (~460MB) | Balanced quality/speed |
| **High** | 8-16GB | Dedicated | `whisper-medium.en` (~1.5GB) | High accuracy |
| **Ultra** | 16GB+ | Dedicated 8GB+ | `whisper-large-v3` (~3GB) | Maximum accuracy, multilingual |

### Mobile-Specific Recommendations

| Platform | RAM | Thermal State | Recommended Model |
|----------|-----|---------------|-------------------|
| iOS | < 4GB | Any | `whisper-tiny.en` |
| iOS | 4-6GB | Nominal | `whisper-base.en` |
| iOS | 4-6GB | Serious+ | `whisper-tiny.en` (downgrade) |
| Android | < 4GB | Any | `whisper-tiny.en` |
| Android | 4-6GB | Headroom > 0.7 | `whisper-base.en` |
| Android | 4-6GB | Headroom < 0.7 | `whisper-tiny.en` (downgrade) |

## Configuration Schema

**Location:** Platform-specific config directory
- Linux: `~/.config/lexicon/config.toml`
- macOS: `~/Library/Application Support/lexicon/config.toml`
- Windows: `%APPDATA%\lexicon\config.toml`

**Schema:**

```toml
# Lexicon Local Server Configuration
# Generated by first-run wizard, editable by user

[transcription]
# Default transcription model (used when no model specified)
default_model = "whisper-base.en"

# Path to model file (auto-populated on download)
model_path = "/path/to/models/whisper-base.en.bin"

# Language preference (ISO 639-1 code, or "auto" for detection)
default_language = "en"

[system]
# System profile tier (detected on first run)
profile_tier = "medium"

# Last profiled timestamp
last_profiled = "2026-01-23T12:00:00Z"

# Override automatic model recommendations
auto_recommend = true

[models]
# Downloaded models registry
# Format: model_id = { path, size_bytes, downloaded_at, verified }

[models.whisper-base-en]
path = "/path/to/models/whisper-base.en.bin"
size_bytes = 147951465
downloaded_at = "2026-01-23T12:05:00Z"
verified = true

[tts]
# Default TTS voice (optional)
default_voice = "af_heart"

# Fallback to platform TTS if Kokoro unavailable
platform_fallback = true

[server]
# Default server bind address (for server mode)
bind_address = "127.0.0.1"
port = 8080
```

## Interface Contract

```rust
// lexicon-core/src/config/mod.rs

use std::path::PathBuf;
use serde::{Deserialize, Serialize};

/// System profile tier based on hardware capabilities.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum SystemTier {
    Minimal,  // < 4GB RAM, no GPU
    Low,      // 4-6GB RAM, no GPU
    Medium,   // 6-8GB RAM, integrated GPU
    High,     // 8-16GB RAM, dedicated GPU
    Ultra,    // 16GB+ RAM, high-end GPU
}

/// Hardware profile of the user's system.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SystemProfile {
    pub tier: SystemTier,
    pub ram_gb: f32,
    pub cpu_cores: usize,
    pub cpu_arch: String,
    pub gpu_available: bool,
    pub gpu_name: Option<String>,
    pub gpu_vram_gb: Option<f32>,
    pub disk_free_gb: f32,
    pub platform: String,
}

/// Transcription configuration.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TranscriptionConfig {
    pub default_model: String,
    pub model_path: Option<PathBuf>,
    pub default_language: String,
}

/// Complete application configuration.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LexiconConfig {
    pub transcription: TranscriptionConfig,
    pub system: SystemConfig,
    pub models: HashMap<String, ModelEntry>,
    pub tts: TtsConfig,
    pub server: ServerConfig,
}

impl LexiconConfig {
    /// Load configuration from default location.
    /// Returns None if config doesn't exist (first run).
    pub fn load() -> Result<Option<Self>>;

    /// Save configuration to default location.
    pub fn save(&self) -> Result<()>;

    /// Get default config path for current platform.
    pub fn default_path() -> PathBuf;

    /// Check if this is a first run (no config exists).
    pub fn is_first_run() -> bool;
}

/// System profiler for hardware detection.
pub struct SystemProfiler;

impl SystemProfiler {
    /// Profile the current system hardware.
    pub fn profile() -> Result<SystemProfile>;

    /// Recommend a model based on system profile.
    pub fn recommend_model(profile: &SystemProfile) -> ModelRecommendation;

    /// Get all models suitable for this system profile.
    pub fn suitable_models(profile: &SystemProfile) -> Vec<ModelInfo>;
}

/// Model recommendation with rationale.
#[derive(Debug, Clone)]
pub struct ModelRecommendation {
    pub model_id: String,
    pub model_name: String,
    pub size_bytes: u64,
    pub rationale: String,
    pub alternatives: Vec<ModelInfo>,
}

/// First-run wizard for interactive setup.
pub struct FirstRunWizard;

impl FirstRunWizard {
    /// Run the first-run wizard (CLI interactive).
    pub async fn run() -> Result<LexiconConfig>;

    /// Run non-interactive setup with defaults.
    pub async fn run_headless() -> Result<LexiconConfig>;
}
```
